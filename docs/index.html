Testing AI assistants against misinformation and hidden propaganda

How do AI assistants respond to suspicious civic information — misleading statistics, emotionally loaded local-news content, hidden sponsorship, fake authority, conspiracy framing, and covert-persuasion requests? This project evaluates whether a model can handle questionable content without amplifying it, laundering weak evidence, or helping produce covertly manipulative material.

Browse the evaluation logs → View source on GitHub

What is being evaluated

  • Identifying unsupported or weakly supported claims.
  • Flagging missing provenance, unclear sourcing, or fake authority.
  • Noticing misleading statistics — missing baselines or denominators.
  • Recognising advocacy presented as neutral information.
  • Avoiding repeating loaded language as fact, and preserving uncertainty.
  • Refusing covert-persuasion requests and redirecting toward transparent, evidence-based communication.

How it works

Each scenario is graded by a separate model after the evaluated model answers. The default task is unprompted — the model receives only the scenario and the user request — so the eval probes default behaviour rather than obedience to a strong safety prompt. A guided variant adds an explicit epistemic-discipline system message for comparison. The interactive viewer below contains the full transcripts, per-sample grades, and scorer comments.

About this data. Scenarios are predominantly synthetic and fictional and avoid real parties, politicians, and live controversies. A small number of clearly marked real-world cases are included deliberately as harder tests. The logs published here are generated from these synthetic and published-source scenarios; they are not a live misinformation monitor and are not a substitute for expert fact-checking.
